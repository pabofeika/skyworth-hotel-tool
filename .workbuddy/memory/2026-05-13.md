## 创建酒店 n8n 工作流本地化工具

- 分析了从 URL `https://n8n.lingger.online/workflow/vO8KqA3A3mpMlWEG-SX_M` 导出的 "创建酒店.json" 工作流
- 工作流包含 12 个节点（3个禁用），核心流程：chat输入 → 环境 → 登录 → 新增酒店 → 切换酒店 → 复制模板 → 更新欢迎词 → 汉字转化(DeepSeek) → 新增用户 → 判断成功/重命名重试
- 创建了本地 Node.js + Express 工具，位于 `create-hotel-tool/` 目录
- 工具特性：实时 SSE 进度输出、Web UI 界面、完整的错误处理和重试逻辑、支持 DeepSeek API 和本地拼音备选
- 依赖: express, axios, form-data
